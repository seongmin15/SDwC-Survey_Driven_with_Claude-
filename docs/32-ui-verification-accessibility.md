# UI Verification — Accessibility

> UI가 기본적인 접근성 기준을 충족하는지 검증합니다.
> 이 문서는 프로젝트 시작 시 30-user-flow.md 기반으로 AI가 채웁니다.

## Target Standard

- WCAG 2.1 Level AA (MVP 기본 수준)

## Verification Scope

> **ID Convention**: Use `A-NNN` (e.g., A-001, A-002). Each test case MUST have a unique ID.

#### Survey 페이지 — 접근성

| ID | 테스트 케이스 | 기대 결과 |
|----|-------------|----------|
| A-001 | Tab 키로 모든 폼 필드 순서대로 이동 가능 | 논리적 순서의 포커스 이동 |
| A-002 | Enter/Space로 제출 버튼 활성화 | 폼 제출 동작 |
| A-003 | 모든 입력 필드에 `<label>` 또는 `aria-label` 존재 | 스크린 리더 읽기 가능 |
| A-004 | 필수 필드에 `required` 또는 `aria-required="true"` 설정 | 스크린 리더가 필수 여부 안내 |
| A-005 | 검증 에러 시 에러 메시지가 해당 필드와 연결 (`aria-describedby`) | 스크린 리더가 에러 읽기 |
| A-006 | 검증 에러 시 포커스가 첫 번째 에러 필드로 이동 | 포커스 이동 확인 |
| A-007 | 페이지 제목(`<title>`)과 `<h1>`이 존재 | 스크린 리더 페이지 식별 가능 |
